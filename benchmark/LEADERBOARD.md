# Leaderboard

Generated by `leaderboard.py`. Every model is evaluated with `bench.py evaluate` on exactly the same tasks. Recall@100: fraction of a disease's drugs found in the top 100 of the 7,957 candidates (mean over diseases). Precision@K: hits in the top K, K = number of the disease's drugs. AUPRC: TxGNN's protocol (positives vs as many random approved drugs). To add a model: [SUBMITTING.md](SUBMITTING.md).
