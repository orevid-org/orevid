## NeDRex

Checked on 22-10-2026: the NeDRex API (https://api.nedrex.net, v2.0.0a) has open endpoints for closeness centrality and
TrustRank (`/open/closeness/submit`, `/open/trustrank/submit`) that rank drugs from a list of seed genes using only its
protein network and drug–target edges, not drug indications. With each split's training disease genes as seeds it would
therefore be **comparable** (no test drug–disease edge involved). It needs one remote job per test disease (≥ 1,300 for
the benchmark, the areas and the external exam), so it was **not run** on 22-10, to keep the night's runs local and not
load a public academic service with thousands of jobs. Next step: a first run on zero-shot seed 1 (~70 jobs), reported
as an external baseline.

Implementation note: the first full run failed on a SciPy argument and the z-score divided by a near-zero spread for
drugs whose distance does not change across random sets; both were fixed before the reported run (z = 0 when there is
no spread), without changing any registered choice.
